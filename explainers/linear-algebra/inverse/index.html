Linear algebra · Chapter 5 of 6

Solving Ax = b: inverses, column space and null space

Solving a linear system means finding the input that lands on a given output. Whether there is one answer, none, or infinitely many is decided by what the transformation does to the plane.

A system of equations is a question about a transformation

Take the system

$$\begin{aligned} 2x + y &= 3 \\ x - y &= 0 \end{aligned} \qquad\Longleftrightarrow\qquad \begin{bmatrix} 2 & 1 \\ 1 & -1 \end{bmatrix}\begin{bmatrix} x \\ y \end{bmatrix} = \begin{bmatrix} 3 \\ 0 \end{bmatrix}, \quad\text{i.e. } A\vec x = \vec b.$$

Read geometrically, it asks: which input vector \(\vec x\) does the transformation \(A\) move onto \(\vec b\)? The answer depends on what \(A\) does to the plane as a whole, and the determinant from chapter 4 tells you which of two very different cases you are in.

When det A ≠ 0: run the movie backwards

If \(\det A \neq 0\), the plane is not flattened. Every output point is hit, and by exactly one input: two different inputs landing on the same point would mean their difference is a nonzero vector sent to \(\vec 0\), and then \(A\) would be flattening that direction. So there is exactly one solution.

To find it, undo the transformation. The inverse \(A^{-1}\) is the transformation that puts every point back where it started, so that \(A^{-1}A = I\), "do nothing". Then

$$\vec x = A^{-1}\vec b, \qquad \begin{bmatrix} a & b \\ c & d \end{bmatrix}^{-1} = \frac{1}{ad - bc}\begin{bmatrix} d & -b \\ -c & a \end{bmatrix}.$$

You can check the formula by multiplying it out. The factor \(1/\det A\) is the area picture again: \(A\) scales areas by \(\det A\), so undoing it must scale them by \(1/\det A\), which is impossible when \(\det A = 0\).

When det A = 0: some information is gone

A zero determinant means the plane has been squished onto a line, or onto the origin alone. Two new ideas describe what happened.

The column space is the set of all possible outputs. Every output \(A\vec x = x\,\text{col}_1 + y\,\text{col}_2\) is a combination of the columns, so the column space is the span of the columns (chapter 1). Its dimension is the rank: 2 if the outputs fill the plane, 1 for a line, 0 for the origin alone.

The null space (or kernel) is the set of inputs that land on \(\vec 0\). It always contains \(\vec 0\) itself. It contains more than that exactly when \(\det A = 0\): a squish onto a line crushes a whole line of inputs down to the origin.

Zero, one, or infinitely many

Put the pieces together for \(\det A = 0\):

  • If \(\vec b\) is not in the column space, no input lands on it: the system has no solution.
  • If \(\vec b\) is in the column space, pick any one solution \(\vec x_0\). Adding any null-space vector \(\vec n\) gives another, because \(A(\vec x_0 + \vec n) = A\vec x_0 + A\vec n = \vec b + \vec 0\). And every solution arises this way, since two solutions differ by something \(A\) sends to \(\vec 0\). The solution set is the null space shifted to pass through \(\vec x_0\): a line parallel to the null space.

In the plane the two dimensions are shared out exactly: rank plus the dimension of the null space is 2. A squish onto a line (rank 1) crushes one direction (a null-space line). The zero matrix (rank 0) crushes everything. This bookkeeping, the rank–nullity theorem, holds in every dimension: the dimensions that survive plus the dimensions that are crushed add up to the dimension you started with.

When \(\vec b\) is out of reach, the visualizer also marks the point of the column space closest to it. Choosing \(\vec x\) to land there is what "least squares" means, the standard fallback for systems with more equations than they can satisfy.
