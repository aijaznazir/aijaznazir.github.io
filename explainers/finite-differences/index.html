Numerical methods · Stability

Finite differences: why some schemes blow up

Five reasonable-looking discretizations of the same one-line equation. One is exact at a special time step, some smear, some ripple, and two explode. The reasons fit on a single picture each.

The problem: move a shape without changing it

The advection equation

$$\frac{\partial u}{\partial t} + a\,\frac{\partial u}{\partial x} = 0, \qquad a > 0,$$

says that \(u\) is constant along lines \(x - at = \text{const}\). Its solution is the initial profile sliding to the right at speed \(a\): \(u(x,t) = u_0(x - at)\). Nothing grows, nothing decays, nothing changes shape. Any change you see in a computed solution is the scheme's doing, which makes this the cleanest test there is.

Discretizing

Store values \(u_j^n \approx u(j\Delta x, n\Delta t)\) on a grid and replace derivatives by differences. The time derivative becomes \((u_j^{n+1}-u_j^n)/\Delta t\). For the space derivative there is a choice: look left, look right, or look both ways. Every choice leads to an update of the form "new value = weighted combination of nearby old values", and the weights depend on a single number,

$$c = \frac{a\,\Delta t}{\Delta x},$$

the Courant number: how many grid cells the true solution moves in one step.

SchemeUpdate \(u_j^{n+1} =\)
FTCS (central)\(u_j - \tfrac{c}{2}(u_{j+1}-u_{j-1})\)

All five are consistent: as \(\Delta x,\Delta t\to 0\) each reduces to the PDE. Consistency is not enough. Try them.

First picture: where the information comes from

The true value \(u(x_j, t_{n+1})\) equals the value at time \(t_n\) at the foot of the characteristic, the point \(x_j - a\Delta t = x_j - c\,\Delta x\). A scheme can only get this right in general if that point lies within the grid points its stencil actually reads. If it does not, the scheme is computing the new value from data that physically cannot influence it, and no refinement fixes that.

This is the Courant–Friedrichs–Lewy (CFL) condition: the numerical domain of dependence must contain the physical one. For upwind, the stencil spans \([x_{j-1},x_j]\), so it requires \(0\le c\le 1\). Downwind reads \([x_j,x_{j+1}]\), on the wrong side of \(x_j\), so it fails for every \(c>0\). The left diagram in the simulation draws this for each scheme.

The CFL condition is necessary, not sufficient. FTCS reads both neighbours, satisfies it for \(c\le 1\), and blows up anyway. To see why, we need the second picture.

Second picture: what each step does to each wave

All five schemes are linear with constant coefficients, so they act on each Fourier mode separately. Insert a single mode \(u_j^n = e^{ij\theta}\) (θ is the phase change per grid cell; \(\theta = \pi\) is the shortest wave the grid can hold). One step multiplies it by a complex number \(g(\theta)\), the amplification factor. For upwind,

$$g(\theta) = 1 - c + c\,e^{-i\theta},$$

which, as θ varies, traces a circle of radius \(c\) centred at \(1-c\). That circle sits inside the unit circle exactly when \(0 \le c \le 1\). Computing the modulus directly,

$$|g|^2 = 1 - 2c(1-c)(1-\cos\theta),$$

which is at most 1 for all θ precisely when \(0\le c\le1\). After \(n\) steps a mode has been multiplied by \(g^n\). If \(|g|>1\) for any θ, that mode grows geometrically. Rounding error contains every mode, so eventually it dominates. This is von Neumann stability analysis: the scheme is stable when the curve \(g(\theta)\) stays inside the unit circle.

For FTCS, \(g = 1 - ic\sin\theta\) is a vertical segment through 1, and \(|g|^2 = 1 + c^2\sin^2\theta > 1\) for every \(c>0\). It is unconditionally unstable for advection. The modes with \(\theta\) near \(\pi/2\), four cells per wavelength, grow fastest, which is why the blow-up shows up as a short grid-scale wiggle rather than a smooth bulge.

The Lax equivalence theorem ties the pictures together: for a consistent linear scheme, stability is exactly what separates convergence from divergence as the grid is refined.

Stable is not the same as accurate

Inside the unit circle, the curve still says what the scheme does wrong. The modulus \(|g|\) is how much each wave decays per step, and \(\arg g\) compared with the exact \(-c\theta\) is how far it lags or leads. A cleaner way to see both is the modified equation: the PDE the scheme actually solves to the next order in \(\Delta x\). Taylor-expanding the upwind update gives

$$u_t + a u_x = \underbrace{\tfrac{a\Delta x}{2}(1-c)}_{\nu_{\text{num}}}\,u_{xx} + \dots$$

Upwind is the exact equation plus diffusion with a grid-dependent viscosity. That is why it smears the pulse, why the smearing vanishes at \(c=1\) (where \(g = e^{-i\theta}\) and the scheme just copies values one cell over), and why \(c>1\) turns the viscosity negative. Lax–Friedrichs has \(\nu_{\text{num}} = \frac{a\Delta x}{2c}(1-c^2)\), which grows as \(c\) shrinks. Lax–Wendroff cancels the diffusive term and is left with a dispersive one,

$$u_t + a u_x = -\tfrac{a\Delta x^2}{6}(1-c^2)\,u_{xxx} + \dots,$$

so short waves travel too slowly and fall behind sharp features as ripples. No linear scheme beyond first order avoids such oscillations at a discontinuity (Godunov's theorem), which is why shock-capturing methods like the one in the Burgers explainer use nonlinear limiters.
